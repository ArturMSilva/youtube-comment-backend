Política de Privacidade

Vigente desde: 3 de agosto de 2026 Versão: 1.0

Resumo de transparência

O que tratamos

O ID do vídeo aberto, os comentários públicos coletados pela API do YouTube e a pergunta que você digita.

O que não coletamos

Nenhuma conta, login ou identificação pessoal sua. Nenhum dado de navegação fora de páginas de vídeo do YouTube.

Com quem compartilhamos

Provedores necessários ao funcionamento: YouTube Data API e Gemini (Google), Groq, Neon e Vercel.

Como protegemos

As chaves de acesso ficam apenas no servidor; a extensão nunca as vê. Comentários são sempre exibidos como texto puro.

01Sobre esta política

Esta política descreve como a extensão de navegador CommentLens trata dados ao ajudar você a compreender as opiniões expressas nos comentários de vídeos do YouTube. A ferramenta coleta os comentários públicos de um vídeo, seleciona os mais relevantes para uma pergunta feita em linguagem natural e usa um modelo de linguagem para gerar uma resposta fundamentada nesses comentários, exibindo as fontes que a embasaram.

O CommentLens foi desenvolvido no contexto de um Trabalho de Conclusão de Curso do curso de Tecnologia em Análise e Desenvolvimento de Sistemas do Instituto Federal do Piauí (IFPI), Campus Picos. Ao instalar e usar a extensão, você concorda com as práticas aqui descritas.

02Dados que tratamos

A extensão trata apenas os dados estritamente necessários para responder às suas perguntas sobre os comentários:

ID do vídeo
Ao acessar uma página de vídeo do YouTube, a extensão identifica e extrai o identificador do vídeo. Nenhum outro conteúdo da página é lido.
Comentários públicos
Sob seu comando, os comentários públicos do vídeo são coletados pela API oficial do YouTube, ordenados por relevância. Guardamos o texto do comentário, sua contagem de curtidas e sua posição no ranking.
Sua pergunta
O texto que você digita em linguagem natural para consultar os comentários.
Resposta e metadados
A resposta gerada e dados técnicos da interação: método de recuperação usado, modelo de linguagem que respondeu, latência da seleção e data/hora.

O que não é coletado

  • Nenhuma conta de usuário, credencial de login ou identificador pessoal seu.
  • Nenhum dado de navegação em páginas que não sejam vídeos do YouTube.
  • Nenhum dado pessoal do autor dos comentários (como nome ou canal) é armazenado.

03Para que usamos os dados

Os dados são usados exclusivamente para:

  • Recuperar os comentários mais relevantes para a sua pergunta e gerar uma resposta fundamentada, com as fontes que a embasaram;
  • Registrar as interações de forma pareada, para fins de pesquisa acadêmica — a comparação controlada entre duas estratégias de recuperação (léxica e semântica), que é objeto do trabalho.

Não usamos seus dados para publicidade, criação de perfis comerciais ou qualquer finalidade alheia ao funcionamento e à pesquisa aqui descritos.

04Onde os dados ficam armazenados

No seu dispositivo

Os comentários coletados são guardados localmente, no armazenamento do próprio navegador, apenas para restaurar a análise ao reabrir a interface no mesmo vídeo. Esses dados permanecem no seu dispositivo e podem ser apagados a qualquer momento removendo os dados da extensão ou desinstalando-a.

No servidor

As interações (a pergunta, a resposta, o texto dos comentários selecionados e os metadados técnicos) são registradas em um banco de dados relacional (Neon / PostgreSQL) para permitir a comparação entre as estratégias de recuperação. Esse registro é feito em regime de melhor esforço: uma eventual falha na gravação nunca impede que você receba a resposta.

05Compartilhamento com terceiros

Para funcionar, o CommentLens envia dados a provedores externos que atuam como operadores. Cada um recebe apenas o necessário para sua função e é regido pela sua própria política de privacidade:

Google — YouTube Data API v3
Coleta dos comentários públicos do vídeo.
Google — Gemini (embeddings)
A pergunta e os comentários são convertidos em representações vetoriais para a recuperação semântica.
Groq
A pergunta e os comentários selecionados são enviados ao modelo de linguagem que gera a resposta.
Neon
Banco de dados que armazena as interações registradas.
Vercel
Hospeda o backend que intermedeia toda a comunicação com os serviços acima.

Recomendamos consultar as políticas de privacidade desses provedores para entender como tratam os dados que recebem. Não vendemos nem cedemos seus dados a terceiros para fins comerciais.

06Segurança

Adotamos as seguintes medidas técnicas:

  • As chaves de acesso aos serviços externos residem exclusivamente no servidor; a extensão nunca tem contato com credenciais.
  • Toda a comunicação entre a extensão e o backend ocorre por conexão criptografada (HTTPS).
  • O conteúdo dos comentários é sempre exibido como texto puro, nunca interpretado como código, evitando a execução de conteúdo indevido.

Nenhum sistema é completamente imune a riscos. Empregamos esforços razoáveis para proteger os dados tratados, mas não é possível garantir segurança absoluta.

07Retenção e seus direitos

As interações registradas no servidor são mantidas até a conclusão da pesquisa. Como a extensão não coleta identificadores pessoais seus, os registros não estão vinculados à sua identidade.

Você pode, a qualquer momento, apagar os dados armazenados localmente removendo os dados da extensão no seu navegador ou desinstalando-a. Para dúvidas ou solicitações relativas a esta política, utilize o contato ao final do documento.

08Privacidade de menores

O CommentLens não é direcionado a crianças e não coleta intencionalmente dados de menores de idade. A extensão não solicita nem armazena qualquer informação de identificação pessoal do usuário.

09Alterações nesta política

Esta política pode ser atualizada para refletir mudanças na ferramenta ou nos serviços utilizados. Quando isso ocorrer, a data de vigência no topo será revista. Recomendamos consultar esta página periodicamente.
